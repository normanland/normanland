<!-- ====================== ABOUT ====================== -->

## `> whoami`

I'm **Mayil Huseynov** — an **Operations Coordinator and Junior Data Analyst** with an academic background in **Mechatronics & Robotics Engineering**.

I work at the intersection of **data, operations and problem-solving**, turning raw information into structured analysis, meaningful visualizations and decisions that are easier to act on.

My approach to analytics is straightforward:

```text
ask → understand → query → analyze → validate → explain
```

I care about more than producing a chart or writing a query.

The real objective is to understand **what happened, why it happened, whether it matters, and what should happen next**.

📍 Baku, Azerbaijan  
🌍 Open to remote opportunities

<!-- ====================== PRINCIPLES ====================== -->

## `07 / analytical principles`

```diff
+ Start with the problem, not the tool.

+ Understand the data before analyzing it.

+ Keep the workflow reproducible.

+ Validate before interpreting.

+ Question unusual results.

+ Prefer clarity over unnecessary complexity.

+ Use visualizations to reveal information.

+ Translate metrics into business meaning.

+ Make recommendations that can actually be acted on.
```
